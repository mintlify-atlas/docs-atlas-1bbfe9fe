Prowl Anthology is the set of modular C# libraries that power the [Prowl game engine](https://github.com/ProwlEngine/Prowl). Each library ships as its own `Prowl.*` NuGet package and can be used independently in any .NET project — from game engines to desktop tools. They version together in a single repository so cross-library changes land in one commit with no publish chain.

## Why Anthology?

All packages share a **single version number**, set in one place. Tag `vX.Y.Z` and CI builds, packs, and pushes every package simultaneously — no cross-repo version juggling. Use the libraries you need; ignore the rest.
