Prowl.Recast is a single-assembly port of [DotRecast](https://github.com/ikpil/DotRecast) — itself a faithful C# translation of the industry-standard [recastnavigation](https://github.com/recastnavigation/recastnavigation) library powering AI navigation in Unity, Unreal, Godot, O3DE, and countless games. Eight upstream DotRecast projects (`Core`, `Recast`, `Detour`, `Detour.Crowd`, `Detour.Dynamic`, `Detour.TileCache`, `Detour.Extras`, `Recast.Toolset`) are compiled into a single `Prowl.Recast` package. Type names (`Rc*`, `Dt*`) are preserved verbatim from the upstream; only the root namespace changes from `DotRecast.*` to `Prowl.Recast.*`. The dependency on Newtonsoft.Json (used only for A* Pathfinding Project import) is dropped entirely.

## Installation

```bash
dotnet add package Prowl.Recast
```

## Navmesh Generation

Recast builds navigation meshes through a multi-stage voxelization pipeline. Configure the bake with `RcConfig`, then pass it to `RcBuilder`.

```csharp
using Prowl.Recast;
using Prowl.Recast.Core;
using Prowl.Recast.Core.Numerics;
using Prowl.Recast.Geom;

// 1. Describe bake parameters
var cfg = new RcConfig(
    partitionType:                RcPartition.WATERSHED,
    cellSize:                     0.3f,   // XZ cell size
    cellHeight:                   0.2f,   // Y cell height
    agentMaxSlope:                45f,
    agentHeight:                  2.0f,
    agentRadius:                  0.6f,
    agentMaxClimb:                0.9f,
    regionMinSize:                8,
    regionMergeSize:              20,
    edgeMaxLen:                   12f,
    edgeMaxError:                 1.3f,
    vertsPerPoly:                 6,
    detailSampleDist:             6f,
    detailSampleMaxError:         1f,
    filterLowHangingObstacles:    true,
    filterLedgeSpans:             true,
    filterWalkableLowHeightSpans: true,
    walkableAreaMod:              new RcAreaModification(1),
    buildMeshDetail:              true
);

// 2. Supply geometry — wrap your triangle soup
var geom = new RcSampleInputGeomProvider(vertices, indices);

// 3. Build — pass geom + a RcBuilderConfig wrapping the RcConfig
var builder    = new RcBuilder();
var builderCfg = new RcBuilderConfig(cfg, geom.GetMeshBoundsMin(), geom.GetMeshBoundsMax());
RcBuilderResult result = builder.Build(geom, builderCfg, keepInterResults: false);

// 4. Inspect intermediate products if needed
RcPolyMesh       polyMesh   = result.Mesh;
RcPolyMeshDetail detailMesh = result.MeshDetail;
```

The bake pipeline stages in order: **rasterization** (input triangles → `RcHeightfield`) → **filtering** (remove non-walkable spans) → **region** (watershed or monotone partitioning → `RcCompactHeightfield`) → **contour** (trace boundary → `RcContourSet`) → **polygon mesh** (`RcPolyMesh`) → **detail mesh** (`RcPolyMeshDetail`).

## Pathfinding

Create a `DtNavMesh` from the baked poly mesh data, then query paths with `DtNavMeshQuery`.

```csharp
using Prowl.Recast.Detour;

// Build runtime nav mesh from the bake result
DtNavMeshCreateParams navParams = new DtNavMeshCreateParams();
// ... populate from polyMesh / detailMesh fields ...
DtMeshData meshData = DtNavMeshBuilder.CreateNavMeshData(navParams);
var navMesh = new DtNavMesh();
navMesh.Init(meshData, navParams.nvp, 0);

// Create a query object
var query  = new DtNavMeshQuery(navMesh);
var filter = new DtQueryDefaultFilter();

// Find nearest polygon refs for start and end positions
RcVec3f startPos = new RcVec3f(0f, 0f, 0f);
RcVec3f endPos   = new RcVec3f(20f, 0f, 15f);
RcVec3f extents  = new RcVec3f(1f, 1f, 1f);

query.FindNearestPoly(startPos, extents, filter, out long startRef, out _, out _);
query.FindNearestPoly(endPos,   extents, filter, out long endRef,   out _, out _);

// Run A* path query
Span<long> path = stackalloc long[256];
query.FindPath(startRef, endRef, startPos, endPos, filter, ref path, out int pathCount,
               maxPath: 256);

// Smooth the polygon path into a walkable corridor
Span<RcVec3f> smoothPath = stackalloc RcVec3f[2048];
// ... use DtPathUtils.MergeCorridorStartMoved / SteerTarget helpers ...
```

`DtNavMeshQuery` also provides `FindRandomPoint`, `Raycast`, `GetPolyWallSegments`, and `FindPolysAroundCircle` for common navigation queries.

## Crowd Simulation

`DtCrowd` manages a pool of agents that navigate, avoid each other using ORCA (Optimal Reciprocal Collision Avoidance), and follow paths on the navmesh.

```csharp
using Prowl.Recast.Detour.Crowd;

var crowdCfg = new DtCrowdConfig(maxAgentRadius: 0.6f);
var crowd     = new DtCrowd(crowdCfg, navMesh);

// Configure an agent
var agentParams = new DtCrowdAgentParams
{
    radius             = 0.4f,
    height             = 1.8f,
    maxAcceleration    = 8f,
    maxSpeed           = 3.5f,
    collisionQueryRange = 1.2f,
    pathOptimizationRange = 30f,
    separationWeight   = 2f,
};

// Spawn at a world position
DtCrowdAgent agent = crowd.AddAgent(
    new RcVec3f(0f, 0f, 0f), agentParams);

// Request movement to a target
crowd.RequestMoveTarget(agent, endRef, endPos);

// Drive the simulation each frame
var debug = new DtCrowdAgentDebugInfo();
crowd.Update(deltaTime: 1f / 60f, debug);

// Read back the agent's current position for rendering
RcVec3f pos = agent.npos;
```

Key `DtCrowd` methods: `AddAgent`, `RemoveAgent`, `UpdateAgentParameters`, `RequestMoveTarget`, `RequestMoveVelocity`, `ResetMoveTarget`, `GetActiveAgents`, `Update`.

`DtCrowdAgentState` values: `DT_CROWDAGENT_STATE_INVALID`, `DT_CROWDAGENT_STATE_WALKING`, `DT_CROWDAGENT_STATE_OFFMESH`.

## Tile Streaming

`DtTileCache` enables navmesh streaming for large open-world games. Tiles are built offline and loaded/unloaded at runtime as the player moves through the world.

```csharp
using Prowl.Recast.Detour.TileCache;

// Create a tile cache with a compressor and mesh processor
var tcParams = new DtTileCacheParams { /* ... */ };
var tileCache = new DtTileCache(tcParams, new DtTileCacheStorageParams(),
    navMesh, compressor, meshProc);

// Load a pre-baked tile from disk
byte[] tileData = File.ReadAllBytes($"tiles/{tx}_{tz}.tile");
long tileRef = tileCache.AddTile(tileData, flags: 0);

// Update the tile cache — processes pending re-bake requests
bool upToDate = tileCache.Update();
```

Unloading is handled by `tileCache.RemoveTile(tileRef)`.

## Dynamic Obstacles

Add and remove obstacles on the navmesh at runtime with the `DtDynamic` module. Obstacles are described as geometric volumes that punch holes into or fill previously walkable areas.

```csharp
using Prowl.Recast.Detour.Dynamic;
using Prowl.Recast.Detour.Dynamic.Colliders;

// Create a dynamic navmesh from a DtVoxelFile (pre-built voxel data)
var dynNavMesh = new DtDynamicNavMesh(voxelFile);

// Add a box obstacle (e.g. a fallen crate)
// DtBoxCollider takes center, half-edge vectors, area ID, and merge threshold
long obstacleRef = dynNavMesh.AddCollider(
    new DtBoxCollider(center, halfEdges, area: 1, flagMergeThreshold: 0.1f));

// Rebuild the affected tiles; returns true when all tiles are up to date
bool done = dynNavMesh.Update();

// Remove the obstacle later
dynNavMesh.RemoveCollider(obstacleRef);
```
